Custom fonts
============

Drop any .ttf or .otf font file into this folder (subfolders work too),
then pick it on the main menu under "Font style" with the < and > buttons.

The font's name in the game comes from its file name, so a file called
my-font.ttf shows up as "my-font".

Fonts that ship with Windows (Segoe UI, Arial, Calibri, Verdana, Trebuchet MS,
Georgia, Times New Roman, Comic Sans MS, Impact, Consolas and Courier New) are
listed automatically when they are installed on your PC, so no files are needed
for those. "Default" is raylib's small built-in bitmap font: it is only a
fallback and looks chunky when it is enlarged, which is why the game starts on a
real font instead.

Text is rasterised at the size it is shown at, so every choice stays sharp.
