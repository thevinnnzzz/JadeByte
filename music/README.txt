Background music
================

The game already has two tracks that it generates itself, so this folder can
stay empty:

  Theme  - the calm track the game used when it had only one
  Arcade - a brighter, faster second track

Drop any .wav, .ogg, .mp3 or .qoa file into this folder (subfolders work too)
and it is added to the "Music" row on the main menu, named after its file:
ph_music.wav shows up as "ph_music".

Use the < and > buttons on the Music row to switch tracks; the new track starts
playing straight away. The Music row is read from the folder the game was
started in, so keep the game in its own folder and launch it from there.
